Privacy Policy

Last updated {{ updated }}

This site has no accounts, sets no cookies and runs no analytics. It asks you for nothing, and it stores nothing about you on a server anywhere.

What is stored on your device

One thing, and only if you use the theme toggle: a browser localStorage entry named theme, holding the word dark or light. It never leaves your browser and nothing reads it but this page. Clearing site data for this domain removes it. Until you toggle, the site simply follows your operating system's light/dark preference.

What your browser requests when you visit

Like any web page, the requests below reveal your IP address and user agent to whoever answers them. Nothing here is a tracker, but you should know they happen:

  • GitHub Pages serves the page itself, the fonts and the images.
  • This site's own API (a small read-only service on Render) returns the project, profile and resume text. It has no database, stores no request data and reads nothing about you.
  • api.github.com is asked for the owner's public GitHub activity, to show the "last push" line. It is a public, unauthenticated endpoint; no identifier of yours is sent.
  • Each project's own site is pinged once — and only once its status dot scrolls into view — to show whether that deployment is currently answering. Nothing is sent beyond the request itself, and the reply cannot be read by this page.

Fonts are served from this site, not from a font CDN, so no third party learns of your visit that way. There are no embedded videos, no tag managers, no advertising and no social widgets.

Logs kept by the hosts

GitHub (Pages) and Render (the API) keep their own request logs, which include IP addresses, under their own retention policies. Render's dashboard shows the API's recent request logs to the owner of this site. No other logging is added, and nothing is exported, aggregated or profiled.

If you email me

The address in the footer is a normal mailbox. If you write to it, your message and address sit in that mailbox and are used to reply to you — nothing else, and never passed to anyone else.

Your choices

There is no account to delete and no profile to request. Clearing site data removes the theme preference; blocking scripts for this domain leaves the prerendered text of every page readable, because the site is served as finished HTML.
